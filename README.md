# Martyr
A simple program to simulate human writting to fool microsoft team's activity monitor

## 🛠 Requirements
- Python 3.12.4 or higher  
- lorem_text 3.0
- numpy 2.4.4
- pyautogui 0.9.54
- pynput 1.8.1
- sounddevice 0.5.5


## 💾 Installation

### From source
1. Download [Python 3.12.4 or higher](https://www.python.org/) if you don't have it yet
2. Download the zip and extract (or clone using Git)  
3. Run `pip install -r requirements.txt` on a terminal 
    - *A virtual enviroment is highly recommended*
4. Run `main.py`  

### From exe
1. Download the zip and extract  
2. Run `Martyr.exe`  (or `Martyr` on Linux)


## 💡 Example Usage
1. Run the program
2. As the countdown starts, switch to a tab to type
3. Let it run, it will begin typing at random intervals
4. Stop at any time with ESC
